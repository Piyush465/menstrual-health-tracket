# Contributing

This repository is primarily an academic Experiential Learning Project, but suggestions and improvements are welcome.

## How to Contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make and test your changes.
4. Keep the existing C++ style readable and consistent.
5. Commit with a clear message.
6. Open a pull request describing the improvement.

## Suggested Contribution Areas

- Input validation
- Persistent history storage
- Full undo/redo functionality
- Variable cycle length support
- Recommendation improvements
- Tests
- Documentation
